INSTALL ON ANDROID
1. Extract the ZIP.
2. Upload the folder to a web server/hosting (PWA installation needs HTTPS or localhost).
3. Open index.html through the hosted HTTPS address in Chrome.
4. Chrome menu -> Add to Home screen / Install app.
5. The app icon can then be opened like a normal app.

IMPORTANT:
- Data is stored in the browser's localStorage on the device/browser.
- Use Reports -> Download Backup regularly.
- This package is a frontend/offline prototype and does not include a cloud database or APK binary.
- For multi-user/cloud access, a PHP/MySQL or Firebase backend should be connected.
